# 川渡りパズル

全員を船で向こう岸へ渡す、古典的な川渡りパズルを5ステージ収録した単体HTMLアプリです。選択教科の数学の授業で生徒が盛り上がった題材を、アプリとして再構成しました（ルール文・コードはすべてオリジナル）。

## ステージと条件（すべて自前ソルバーで解法と最短手数を検証済み）

| ステージ | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 古典編（農夫・オオカミ・ヤギ・キャベツ） | 定員3（最短3手） | 定員2（最短7手） | 定員2＋ニワトリ（最短9手） |
| ヒトとサル編 | ヒト2・小サル1（最短5手） | ヒト3・小サル2（最短13手） | ヒト5・小サル3（最短15手） |
| 宣教師と人食い編 | 2組（最短5手） | 3組（最短11手） | 4組・定員3（最短9手） |
| 農夫とレタスとライオンとラマ編 | 3つ・定員3（最短3手） | 3つ・定員2（最短7手） | リバイアサン入り＋助手・定員2（最短9手） |
| 家族と警官・泥棒編 | 娘2息子2・定員3（最短7手） | 娘3息子3・定員3（最短11手） | 娘4息子4・定員3（最短15手） |

解けない組み合わせ（宣教師4組・定員2、家族3+3人・定員2、ライオン・ラマ4品・定員2など）は、ソルバーの検証で外しています。

## 機能
- 歩いて乗り降りする人物、櫂を漕いで進む船、水の音と漕ぐ音（Web Audio合成、ミュート可）
- 危ない組み合わせが残る出発は、警告の演出（赤い輪と震え＋警告音）でブロック（「食べる」等の直接表現はしません）
- 手数表示、その条件の最短手数、いまの場所からの最短手数、1つもどす、ヒント（最短路の次の一手）、クリア演出
- ワークシート印刷：ステージ・条件ごとの問題文・条件・手順の記録表・考え欄・ふりかえり欄をA4・300dpi画像で書き出し（ページ内表示＋長押し保存でiPhone対応）
- ホーム画面アイコン（icon.png / icon-180.png）

## ファイル
- `index.html`：完成品（単体・外部リクエストなし）
- `engine.js` / `stages.js`：状態管理・危険判定・BFSソルバーとステージ定義（検証と共用）
- `build-app.js`：template.html に engine/stages/app-logic を埋め込んで index.html を生成
